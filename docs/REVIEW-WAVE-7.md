# گزارش موج ۷ — «یکدست‌سازی کامل پالت تم»

> برنچ کاری: `chore/wave-7-theme-finalize` (رویکرد 🅱️ هوشمند)
> هدف: حذف آخرین رنگ‌های hard-codeِ حساس به تم، تا پالت ۱۰۰٪ توکنی شود.

## ۱) مسئله
پس از موج‌های ۴–۶، هنوز ~۱۲۰ رنگ **متمایز** به‌صورت hard-code باقی مانده بود
(سطوح/حاشیه‌های نزدیک‌سفید، پس‌زمینه‌های ملایم رنگی، متن‌های رنگی، تیره‌های برند).

## ۲) راه‌حل — تولید خودکار توکن
- `tools/gen-theme-tokens.mjs`:
  - تمام CSS و «بلوک‌های `style` داخل JS» را اسکن می‌کند
    (بدون `var(--x, #hex)` و بدون تعریف‌های توکن).
  - برای هر رنگ باقی‌مانده یک توکن `--c-<hex>` می‌سازد و **مقدار تیره** را با
    قاعدهٔ روشنایی/اشباع (HSL) محاسبه می‌کند:
    - نزدیک‌سفید → سطح تیره · خاکستری روشن → حاشیهٔ تیره
    - پس‌زمینهٔ ملایم رنگی → همان hue با روشنایی پایین
    - متن متوسط/عمیق → shade روشن‌تر همان hue
  - خروجی: `tools/theme-token-map.json` + بلوک تولیدی در `global.css`
    (داخل نشانگرهای `@@WAVE7-TOKENS-START/END@@`).
- `tools/migrate-theme-tokens.mjs` نقشهٔ تولیدشده را بارگذاری و با `HEX_MAP` ادغام می‌کند.

## ۳) نتیجه (اندازه‌گیری‌شده)
| سنجه | قبل | بعد |
|---|---|---|
| CSS — رنگ‌های حساس باقی‌مانده | ۳۲۳ مورد / ۱۱۷ متمایز | **۰** |
| JS (بلوک‌های style) — باقی‌مانده | چند ده | **۰** |
| توکن‌های تولیدشده | — | **۱۲۰** |

**مستثناها (عمدی، با یادداشت):** سفیدِ متن (`#fff`/`#ffffff`) و رنگ‌های گرادیانی/تزئینی
اشباع: `#00f2fe`, `#4facfe`, `#43e97b`, `#38f9d7`, `#f093fb`, `#f5576c`, `#764ba2`, `#4a90e2`
(در هر دو تم درست دیده می‌شوند).

## ۴) اعتبارسنجی
```

```

## ۶) نکات آینده
- کیفیت بصری مقادیر تیرهٔ **تولیدشده** باید یک‌بار چشمی مرور شود (قاعدهٔ خودکار، دقیق اما نه طراحی‌شده).
- اگر بعداً پالت برند رسمی (Figma) آمد، می‌توان `theme-token-map.json` را با مقادیر دستی جایگزین کرد
  و با اجرای همان دو ابزار، همه‌چیز از نو تولید/مهاجرت می‌شود (idempotent).
